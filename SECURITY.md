# Security policy

## Scope

Wayfinder handles sensitive planning information in a local browser context and in files the user chooses to export. Reports involving data exposure, unsafe import handling, cross-site scripting, file handling, dependency compromise, or unintended network transfer are in scope.

## Reporting a vulnerability

Do not open a public issue or attach a proof containing personal data. Use the repository's private security reporting channel. If none is available, ask a maintainer for a private channel before sharing technical details.

Include a minimal synthetic reproduction, affected versions or commits, impact, and suggested mitigation. Do not include credentials, real exports, account identifiers, or private source material.

## Disclosure and fixes

Maintainers will assess the report, reproduce it with synthetic data, and coordinate a fix before public disclosure. Please give maintainers a reasonable opportunity to resolve the issue before publishing details.

## User safety

Treat exported JSON and read-only family HTML reports as sensitive. Store and share them deliberately. Verify imported documents before confirmation, and keep dependencies current through the repository's normal review process.
