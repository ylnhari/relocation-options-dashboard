  architecture, research, official-source, decision-checklist, roadmap, and
  agent-workflow documentation.

  dependency auditing, and GitHub CI.

  with Unicode-length parity and a CI drift gate.

  with Web Locks as an optional outer guard and fail-closed persistence errors.
